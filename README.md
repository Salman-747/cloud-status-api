# Cloud Status API

A Python web API built with FastAPI as a cloud and DevOps learning project.

## Features

- Home endpoint: `/`
- Health endpoint: `/health`
- Application information endpoint: `/info`
- Automated tests using pytest
- API documentation generated by FastAPI

## Requirements

- Python 3.14 or a compatible supported Python version
- pip

## Setup

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
